# ECC research

Исследовательский проект для воспроизводимых экспериментов с rateless-кодами.
Общая реализация находится в `notebooks/_shared`, а сами ноутбуки оставляют
постановку эксперимента, параметры и интерпретацию результата.

## Подготовка окружения

```powershell
uv sync --group dev
uv run python -m ipykernel install --user --name ecc-research --display-name "Python (ecc-research)"
uv run jupyter lab
```

## Интерактивная лаборатория Primitive Rateless

Откройте `notebooks/primitive_rateless_interactive.ipynb` в ядре проекта:

1. Выполните настройку и ячейку редактора. Меняйте x, N, T и редактируйте y′.
2. Когда наблюдение готово, запустите **Decode the current observation**.
3. Выполните три ячейки Plotly с метриками, отдельными битами и эволюцией LLR.

Правки в редакторе не запускают декодирование и не обновляют графики.
`result = decode(**editor.snapshot())` фиксирует копию входных данных и выполняет
один расчёт. Результаты доступны в `result.history`, `result.truth`, `result.terms`
и `result.scores`. Последующие правки редактора не меняют завершённый результат.

Полином задаётся списком ненулевых степеней `P`, по умолчанию `(0, 2, 5)`.
K вычисляется из P. Примитивность принимается на доверии; A и G не создаются.
Кодирование использует разреженную рекуррентность LFSR и работает также при K=32
и K>64. Для наличия проверок выбирайте N>K.

В `notebooks/_shared` находятся LFSR, синхронные итерации soft-XOR, метрики,
редактор anywidget и функции построения Plotly. Численные циклы ускорены через
`numba.njit(cache=True)`; первый вызов может включать компиляцию. История занимает
`8 * (T + 1) * N` байт, не считая графиков и их копий данных. Документация
внутри ноутбука — на английском.
